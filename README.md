# Portfolio Website (v1)

An earlier version of my personal portfolio site, built with plain HTML, CSS and JavaScript. It introduces who I am and the kind of work I do.

> My current portfolio lives in the [portfolio](https://github.com/Tshepo1000/portfolio) repository. This repo is kept as a record of my first version.

## Getting started

```bash
git clone https://github.com/Tshepo1000/portfolio_website.git
cd portfolio_website
```

Open `index.html` in your browser. No build step or dependencies are needed.

## Project structure

```
portfolio_website/
├── index.html   # page markup
├── style.css    # styling
└── script.js    # interactivity
```

## Tech stack

HTML5, CSS3 and vanilla JavaScript.
